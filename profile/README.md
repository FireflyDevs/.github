## 我们在做什么

FireflyDevs 想和所有喜欢流萤、喜欢《崩坏：星穹铁道》的玩家一起，做一个友善、用心、可以长期维护的同好网站。

我们目前正在开发 **FireflyLoveSite**：

- 页面：流萤主题首页、角色介绍、图集、视频、资料库
- 内容：角色故事、官方资讯、活动资讯、壁纸与同人作品
- 技术：HTML / CSS / JavaScript + TypeScript + Node.js
- 目标：让喜欢流萤的人有一个可以一起分享、一起建设的地方

当前网站仍在筹备中，页面内容不是最终版本，欢迎大家一起补充和改造。

## 参与开发

所有人都可以参与，不限于代码：

- 前端开发、交互与响应式适配
- UI / 视觉 / 动效设计
- 角色资料、活动资料、图集与视频整理
- 文案、翻译、测试和 Issue 整理
- TypeScript / Node.js 后端与部署

### 提交 PR

1. Fork [FireflyLoveSite](https://github.com/FireflyDevs/FireflyLoveSite)
2. 从 `dev` 分支创建功能分支
3. 完成修改，运行 `node server.ts` 和 `pnpm typecheck`
4. 提交 Pull Request，目标分支选择 **`dev`**

PR 会自动运行 TypeScript 类型检查、首页与跳转检查。检查通过并完成维护者审批后，会自动合并到 `dev`，并更新到 [开发预览站](https://dev.xn--qzw410c.love)。

### 加入开发团队

如果你愿意长期参与维护：

1. 在 [FireflyLoveSite Issues](https://github.com/FireflyDevs/FireflyLoveSite/issues) 提交「申请加入开发团队」
2. 简单介绍你的 GitHub 用户名、擅长方向、可投入时间和想参与的部分
3. 也可以加入 [QQ 群](https://qm.qq.com/q/guZg2hdNE4) 联系维护者
